# Pf1 – Basis Flask Experiment

## Doel
Dit is het eerste experiment met **Python Flask**.
Het doel is om een minimale webserver op te zetten die een statische HTML-tekst teruggeeft. Dit bewijst dat de ontwikkelomgeving correct is ingericht en dat Python requests kan afhandelen.

## Context
* **Framework:** Flask (Python Microframework)
* **Poort:** 5051
* **Interface:** 0.0.0.0 (Bereikbaar vanaf elke netwerkinterface)

## Bestanden
* **`app.py`**: Het Python script dat de webserver start en de route `/` definieert.
* **`README.md`**: Deze documentatie.

pip3 install flask
