# Ap3 - Eigen API Experiment (Python)

## Beschrijving
Dit project demonstreert een eenvoudige REST API geschreven in Python (met behulp van de Flask module).
De applicatie serveert data in **JSON-formaat**, wat standaard is voor moderne API-communicatie (zoals besproken in de DevNet slides).

## Onderdelen
* **my_api.py**: Het Python script dat de webserver start en de API endpoints definieert.
* **JSON Response**: De API geeft een lijst van boeken terug in plaats van HTML.

## Vereisten
* Python 3
* Flask (`pip install flask`)

## Gebruik

### 1. Start de applicatie
Voer het script uit in de terminal:
```bash
python3 Ap3.py
